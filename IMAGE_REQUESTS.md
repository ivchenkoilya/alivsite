# IMAGE_REQUESTS — изображения для ALIV SPORT (создаются в ChatGPT)

Сайт уже работает без этих изображений: в каждом слоте стоит реальная фотография с текущего сайта или аккуратная заглушка нужных пропорций. Когда изображение готово:

1. Положите файл по указанному пути (папка `assets/img/generated/`).
2. Пропишите путь в `assets/js/config.js` → `images` (ключ указан у каждого изображения).
3. Пересоберите сайт: `npm run build`.

**Общие правила для всех запросов**

- Без текста, логотипов и надписей на изображении — весь текст накладывается вёрсткой (HTML/CSS).
- Палитра: глубокий чёрный `#0B0C0E`, графит `#141619`/`#22252A`, акцент — тёплый оранжевый `#FF6A00` (только как световой акцент, не заливка).
- Свет: студийный, контрастный, «дорогой»; без кислотных неоновых эффектов.
- Если на изображении есть тренажёр ALIV SPORT — **только по реальной фотографии**, приложенной к запросу. Конструкцию, пропорции, цвет рамы (чёрный, жёлтые элементы — как на фото), количество направляющих, форму спинки и платформы менять нельзя.
- Формат: WebP (качество 80–85). Если ChatGPT отдаёт PNG — конвертируйте в WebP.
- Никаких вымышленных людей-«моделей» на фоне реальных цехов — для производства нужны **реальные фото** (см. приоритет 2).
